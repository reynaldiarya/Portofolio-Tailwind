# Reynaldi Arya - Portfolio

Welcome to the repository for my personal portfolio website. This project showcases my skills, education, recent works, and the services I offer. It is designed with a modern, responsive layout using **HTML**, **Tailwind CSS**, and **JavaScript**.

## 🚀 Features

- **Responsive Design:** Optimized for all devices, from mobile phones to desktops.
- **Dynamic Effects:** Includes particle background effects (`particles.js`) and typing animations (`typed.js`).
- **Modern UI:** Clean and professional interface built with Tailwind CSS.
- **Sections:**
  - Hero Section with Author Profile
  - About Me (Skills & Education)
  - Services Offered
  - Latest Works/Portfolio
  - Experiences
  - Footer with Copyright

## 🛠️ Tech Stack

- **HTML5** - Markup language.
- **Tailwind CSS** - Utility-first CSS framework for styling.
- **JavaScript** - For interactivity and animations.
  - [Typed.js](https://github.com/mattboldt/typed.js/) - Typewriter effect.
  - [Particles.js](https://github.com/ VincentGarreau/particles.js/) - Particle background.

## 📦 Installation & Setup

To get a local copy up and running, follow these simple steps.

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/reynaldiarya/Portofolio-Tailwind.git
    cd Portofolio-Tailwind
    ```

2.  **Install dependencies:**
    Make sure you have [Node.js](https://nodejs.org/) installed.
    ```bash
    npm install
    ```

## 📜 Usage

This project uses Tailwind CSS CLI to compile styles.

### Development

To watch for file changes and rebuild the CSS automatically during development:

```bash
npm run dev
```

### Production Build

To minify the CSS for production:

```bash
npm run build
```
